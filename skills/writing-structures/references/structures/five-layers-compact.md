# Five Layers (Compact)

## Overview
Đào sâu qua 5 tầng, mỗi tầng bóc thêm một lớp ý nghĩa. Dừng ở mỗi lớp để hỏi "Tại sao?", "Thực sự là gì?", "Nếu ngược lại?". Tầng 1, 3, 5 luôn xuất hiện.
**Triết lý:** Surface → Structure → Tension → Connection → Synthesis

## Phases
### 1. SURFACE (Opening)
Giả định phổ biến hoặc quan sát bất ngờ → phác họa bài toán → câu hỏi dẫn dắt.
> "Hầu hết chúng ta tin rằng [X]. Nhưng [tác giả] đặt câu hỏi khác..."

### 2. STRUCTURE (Dev Layer 1)
Ý chính + khung logic + giả định ngầm được gọi tên. "Giả định này có đứng vững không?"

### 3. TENSION (Dev Layer 2)
Phản biện thật (không straw man) + đa góc nhìn + giới hạn áp dụng. Tạo cognitive dissonance.

### 4. CONNECTION (Dev Layer 3)
Kết nối cross-domain + ứng dụng thực tế + mirror pattern (cùng nguyên lý, khác lĩnh vực).

### 5. SYNTHESIS (Closing)
Đúc kết (KHÔNG tóm tắt) + nguyên lý bất biến + câu hỏi mở. Không kết luận cứng.
