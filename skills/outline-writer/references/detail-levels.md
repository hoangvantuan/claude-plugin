# Detail Level Mapping

Quy tắc cho từng mức L1/L2/L3. Load khi tạo outline để chọn đúng mức content.

**Phạm vi**: detail level = **độ phủ nội dung** (coverage depth) — bao nhiêu concepts, examples, data points được đưa vào outline. KHÔNG quy định words/section, font size, độ dài bullet, layout. Đó là việc của writer.

**Đơn vị**: section (1 key point trong outline). Writer sau này chuyển thành slide / paragraph / page tùy media.

## Tổng quan

| Aspect          | L1 (Tổng quan)                            | L2 (Cân bằng)                                    | L3 (Chi tiết)                              |
| --------------- | ----------------------------------------- | ------------------------------------------------ | ------------------------------------------ |
| Số sections     | 5+ (tùy nội dung)                         | 10+ (tùy nội dung)                               | 18+ (tùy nội dung)                         |
| Concepts cover  | Chỉ thesis + key arguments + key metrics  | Thesis + arguments + 1 example/concept chính + comparisons | Tất cả concepts + examples + edge cases + code |
| Examples        | None (hoặc 1 đại diện nếu Giáo dục)       | 1 ví dụ cụ thể mỗi concept chính                 | Tất cả ví dụ relevant                      |
| Code/Config     | None                                      | Trích đoạn ngắn cho concepts quan trọng          | Code đầy đủ                                |
| Data points     | Chỉ key metrics quyết định → metric sections | Moderate + so sánh                              | Comprehensive, dùng bảng/list có cấu trúc  |
| Opening         | Title + Hook (2)                          | Title + Hook + Agenda (3)                        | Title + Hook + Agenda (3)                  |
| Closing         | Takeaways (max 2 points) (1)              | Takeaways + CTA (2)                              | Takeaways + CTA (2)                        |
| Transitions     | None (statement/metric thay thế)          | Between major sections                           | Between major sections only                |


## L1 — Executive / Overview Level

L1 = chỉ giữ ý cốt lõi. Audience chỉ đọc/nghe phần này vẫn nắm được thesis.

- **Chỉ giữ**: Thesis statement / kết luận chính của mỗi cluster (1 section per cluster)
- **Chỉ giữ**: Số liệu/metric quan trọng nhất → ưu tiên tạo metric section thay vì lẫn trong content
- **Bỏ tất cả**: Giải thích dài, ví dụ phụ, edge cases, chi tiết cấu hình, code
- **Ngoại lệ ví dụ**: Nếu content nature = Giáo dục, cho phép 1 ví dụ đại diện per cluster
- **Gộp cluster nhỏ**: Nếu clusters liên quan và ngắn, có thể gộp vào 1 section
- **Takeaway section**: Max 2 points

## L2 — Balanced Detail

- Mỗi concept chính PHẢI có ít nhất 1 ví dụ cụ thể hoặc code snippet minh họa (vai trò: ground concept)
- Thông tin cấu hình, parameters, options - liệt kê với mô tả ngắn
- So sánh/phân biệt giữa các options (VD: foreground vs background, scope levels)
- Workflow steps đủ chi tiết để follow (không chỉ tên bước)
- Bỏ qua: edge cases hiếm gặp
- Tách section: Nếu 1 topic có >5 sub-items, tách thành 2 sections

## L3 — Deep Dive

- **Giữ tất cả**: Concepts, ví dụ, code snippets, parameters, options, comparisons, workflows
- **Số sections theo nội dung**: Tạo đủ sections để cover tất cả concepts, không giới hạn trần
- **Data/metrics**: Dùng bảng so sánh hoặc structured list, KHÔNG dump raw data
- **Tách cluster lớn**: Nếu 1 cluster source có >10 sub-topics, tách thành 2-3 sections với transition
- **Mỗi section vẫn = 1 concept**: Dù chi tiết, vẫn giữ nguyên tắc 1 section = 1 key point
- **Transitions**: Thêm transition section giữa major clusters only (không giữa sub-clusters)
