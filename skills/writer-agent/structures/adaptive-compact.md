# Adaptive (Compact)

## Overview
Flexible structure. Subagent chooses organization based on content. Dùng khi content mixed hoặc không fit structures cố định.
**Triết lý:** Content-driven organization, không ép nội dung vào khuôn

## Guardrails
1. Opening: MUST use SERIES_CONTEXT.opening_technique
2. Clear 3-part flow: Hook → Development → Closing
3. Each H2 has clear purpose. Max 5 H2s, 300-800 words each
4. Closing connects to next_article. Match voice register (casual=open question, formal=summary+action)

## Development Strategy (by CONTENT_TYPE)
- `tutorial` → Intuition/Concept/Example/Apply (Building Blocks style)
- `conceptual` → Surface/Deeper/Connections (Five Layers style)
- `narrative` → Scene/Encounter/Transformation (Story Arc style)
- `analysis` → Conclusion/Evidence/Implications (BLUF style)
- `mixed` → Combine techniques. Start with dominant type, weave others in

## Constraints
- Narrative transitions between H2 sections (not mechanical)
- Don't switch organization style mid-section (pick per H2)
- KHÔNG lặp opening technique giữa 2 bài liên tiếp
