# Building Blocks (Xây Dựng Từng Bước)

## Overview

Cấu trúc xây dựng kiến thức từ đơn giản đến phức tạp, mỗi block là nền tảng cho block tiếp theo. Giống cách xây nhà: móng trước, tường sau, mái cuối. Người đọc không bao giờ bị overwhelm vì mỗi bước đều dựa trên bước trước.

**Triết lý:** Intuition trước → Concept → Ví dụ → Ứng dụng

## Phases

### 1. Opening

- Câu hỏi người đọc đang thắc mắc hoặc tình huống thực tế
- BLUF: kết luận ngay câu đầu khi phù hợp
- Context ngắn gọn, tạo motivation cho người đọc

### 2. Development (Building Blocks)

**Pattern:** Intuition trước → Concept đơn giản → Ví dụ trực quan → Chi tiết khi cần → Ứng dụng thực tế

Mỗi khái niệm có:
- Giải thích intuition bằng analogy quen thuộc trước
- Định nghĩa đơn giản (1-2 câu)
- Ví dụ minh họa cụ thể
- Liên kết với ứng dụng thực tế

### 3. Closing

- Tóm tắt các điểm chính
- Ý nghĩa thực tiễn
- Lời khuyến khích: người đọc có thể bắt đầu ngay

## Content-Type Adaptation

| Content Type | Điều chỉnh | Lý do |
|---|---|---|
| `tutorial` | Hook → Foundation → Steps → Practice → Summary | Tutorial cần steps rõ ràng |
| `conceptual` | Question → Intuition → Framework → Application | Lý thuyết cần intuition-first |
| `narrative` | Scene → Problem → Building understanding → Insight | Narrative cần story framing |
| `analysis` | Finding → Simple explanation → Evidence → Implications | Phân tích cần accessible entry |
| `mixed` | Dùng cấu trúc mặc định | Nội dung hỗn hợp |

- [ ] Intuition trước, chi tiết sau?
- [ ] Mỗi block xây trên block trước?
- [ ] Analogies gần gũi?
- [ ] Practical applications?

### Closing
- [ ] Summary rõ ràng?
- [ ] Ý nghĩa thực tiễn?
