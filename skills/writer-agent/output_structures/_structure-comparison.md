# Structure Comparison Matrix

Quick reference để chọn structure phù hợp.

## Overview Table

| Structure           | Based On                | Phases                                                 | Best For                                | Complexity |
| ------------------- | ----------------------- | ------------------------------------------------------ | --------------------------------------- | ---------- |
| **BLUF-Evidence**   | Professional            | Executive Summary → Evidence → Action                  | Reports, proposals, analysis            | Trung bình |
| **Building Blocks** | Explanatory             | Hook → Intuition → Concept → Example → Apply           | Tutorials, education, docs              | Dễ         |
| **Five Layers**     | Deep Dive               | Surface → Structure → Tension → Connection → Synthesis | Research, philosophy, complex topics    | Khó        |
| **Spiral Return**   | Introspective Narrative | Moment → Spiral deeper → Open ending                   | Essays, memoirs, reflections            | Khó        |
| **Master-Student**  | Mindful Dialogue        | Experience → Dialogue → Silence                        | Wisdom, zen, mentorship                 | Khó        |
| **Story Arc**       | Mindful Storytelling    | Scene → Encounter → Deepening → Transformation         | Journeys, narratives, spirituality      | Khó        |
| **Depth-Practice**  | Mindful Educator        | Present moment → Layered understanding → Practice      | Education + philosophy, career guidance | Trung bình |


## Decision Tree

```
Mục đích chính của bài viết là gì?

├─ Truyền tải thông tin / phân tích
│   ├─ Cần kết luận ngay, data-driven → BLUF-Evidence
│   ├─ Cần dạy concept, step-by-step → Building Blocks
│   ├─ Cần đào sâu, phản biện → Five Layers
│   └─ Cần balance chiều sâu + thực hành → Depth-Practice
│
├─ Kết nối cảm xúc / kể chuyện
│   ├─ Hành trình cá nhân, chiêm nghiệm → Spiral Return
│   └─ Kể chuyện có nhân vật, bối cảnh → Story Arc
│
├─ Đối thoại / gợi mở
│   └─ Đối thoại thầy-trò, hỏi-đáp → Master-Student
```

## Closing Style

| Structure       | Cách kết thúc           | Người đọc mang theo            |
| --------------- | ----------------------- | ------------------------------ |
| BLUF-Evidence   | Recommendations cụ thể  | Action items                   |
| Building Blocks | Summary + encouragement | Confidence để bắt đầu          |
| Five Layers     | Câu hỏi mở              | Câu hỏi để tiếp tục nghĩ       |
| Spiral Return   | Hình ảnh tĩnh lặng      | Cảm giác bình yên + câu hỏi    |
| Master-Student  | Im lặng                 | Không gian tự suy ngẫm         |
| Story Arc       | Câu hỏi mới             | Perspective mới                |
| Depth-Practice  | Mời gọi thực hành       | Hành động cụ thể + inspiration |


## Mix-Match Guide

Mỗi structure có thể kết hợp với BẤT KỲ style nào. Một số combo đặc biệt hiệu quả:

| Combo                                              | Hiệu quả | Khi nào                        |
| -------------------------------------------------- | -------- | ------------------------------ |
| Deep Dive voice + BLUF-Evidence structure          | ★★★      | Phản biện nhưng cần actionable |
| Professional voice + Five Layers structure         | ★★★      | Phân tích formal nhưng sâu     |
| Explanatory voice + Depth-Practice structure       | ★★★      | Dạy có chiều sâu triết học     |
| Introspective voice + Story Arc structure          | ★★★      | Tự sự có narrative arc rõ      |
| Mindful Educator voice + Building Blocks structure | ★★★      | Dạy step-by-step có chánh niệm |
