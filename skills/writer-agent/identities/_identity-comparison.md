# Identity Comparison Matrix

Quick reference để chọn writer identity phù hợp.

## Overview Table

| Identity | Category | Role | Worldview | Evidence Type | Tone |
|---|---|---|---|---|---|
| **Tech Builder** | Technology | Builder/practitioner | Pragmatic optimist | Experience, experiments | Thẳng thắn, tự tin |
| **Contemplative Thinker** | Philosophical | Hành giả/observer | Seek understanding | Trải nghiệm, quan sát | Chậm rãi, chân thành |
| **Knowledge Curator** | Analytical | Researcher/connector | Everything connects | Research, reasoning | Tò mò, trung thực |

## Decision Tree

```
Nội dung bạn viết lại chủ yếu về gì?

├─ Technology, product, career, AI
│   └─ Tech Builder
│
├─ Philosophy, mindfulness, inner life, wisdom
│   └─ Contemplative Thinker
│
├─ Research, analysis, cross-domain synthesis
│   └─ Knowledge Curator
│
├─ Mix of above
│   └─ Chọn theo authority chính: ai viết?
│       ├─ Practitioner → Tech Builder
│       ├─ Observer/seeker → Contemplative Thinker
│       └─ Analyst → Knowledge Curator
```
