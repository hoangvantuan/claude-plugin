# Audience Comparison Matrix

Quick reference để chọn audience profile phù hợp.

## Overview Table

| Audience               | Category | Knows                   | Feels                 | Wants                 | Fears              |
| ---------------------- | -------- | ----------------------- | --------------------- | --------------------- | ------------------ |
| **Busy Professionals** | Career   | Khái niệm cơ bản, có KN | Bận, FOMO             | Actionable insights   | Wasting time       |
| **Curious Beginners**  | Learning | Rất ít                  | Excited + overwhelmed | Clarity, step-by-step | Quá khó            |
| **Deep Seekers**       | Depth    | Intermediate+           | Muốn hiểu sâu         | Nuance, connections   | Oversimplification |


## Decision Tree

```
Người đọc bài viết này chủ yếu là ai?

├─ Đã có kinh nghiệm, cần insights nhanh
│   └─ Busy Professionals
│
├─ Mới bắt đầu, cần hiểu từ đầu
│   └─ Curious Beginners
│
├─ Muốn đào sâu, tìm perspectives mới
│   └─ Deep Seekers
│
├─ Không chắc
│   └─ Xem nội dung source:
│       ├─ Introductory → Curious Beginners
│       ├─ How-to, practical → Busy Professionals
│       └─ Analysis, philosophy → Deep Seekers
```
